# 手寫筆記 Word 產生器

成品：A4 Word 檔，每頁是一張 200 DPI 的手寫筆記圖（繁中手寫字型「辰宇落雁體」，每個字的大小、角度、位置都隨機抖動，看起來像人寫的）。
所以 Word 裡**不能直接改字**；要改就改 content 檔重產。

引擎：`scripts/hwnotes.py`（需要 `pip install pillow python-docx fonttools`）。
字型在第一次執行時自動下載到 `fonts/`（見 `fonts/LICENSE-NOTE.md`），之後不用再下載。

## 流程

1. **讀題**：照片直接看；PDF 若讀不到圖（沒裝 pdftoppm），用 pymupdf 抽文字＋把每頁轉 PNG 再看。
   題目引用的圖不在檔案裡 → 照課本標準圖作答，**最後回報時說明這個假設**。
2. **算答案**：用 Python 驗算數值，不要心算。題目數字可疑（例如 93.3 Hz 可能是 MHz）→ 照原題算，再補一行另一種解讀。
3. **落檔位置**：照使用者的資料夾習慣放 docx；content 檔和頁面 PNG 放旁邊的暫存資料夾（例如 `_中間檔/`）。
4. **寫 content 檔**（格式見下），執行：
   ```
   python ~/.claude/skills/handwritten-notes/scripts/hwnotes.py content.py 輸出.docx --png-dir _中間檔/pages
   ```
   Windows 終端機要加 `PYTHONIOENCODING=utf-8`。有「字型缺字」警告就改寫那個符號後重跑。
5. **逐頁 Read PNG 檢查**：字有沒有疊到、答案框對不對、圖裡的標籤有沒有壓到線、光線交點是不是在像上。有問題就改後重跑。
6. **轉 PDF 確認頁數**（避免多出空白頁）：有 LibreOffice 就
   `soffice --headless --convert-to pdf --outdir _中間檔 輸出.docx`，再用 pymupdf 數頁數。
7. **收尾**：刪掉暫存資料夾，回報時附答案表與做過的假設。

## content 檔格式

一個 .py 檔，定義 `NOTES` 串列。引擎的函式自動可用，不用 import。

```python
NOTES = [
  ('h', 'Homework 3  透鏡成像  筆記'),            # 頁首標題（寫在第一條線上方）
  ('t', '公式: 1/p + 1/q = 1/f ,  m = -q/p', 0),  # 一般內容；最後的數字是縮排 0/1/2
  ('gap',),                                        # 空一行
  ('q', '1', '凸透鏡 f = 10 cm, p = 30 cm'),       # 題號（紅圈）＋同一行的題目摘要
  ('t', '1/q = 1/10 - 1/30 = 2/30', 1),
  ('a', 'q = 15 cm (實像, 倒立)', 2),               # 答案：紅字＋「Ans:」＋紅框
  ('fig', lens_diagram(150, 450, 120), FIG_ROWS),  # 圖，佔 FIG_ROWS(=5) 行
  ('brk',),                                         # 強制換頁（通常不需要）
]
```

文字標記：`10^{-19}` 上標、`q_{1}` 下標、`[r]紅字[/r]`。
寫作習慣：每行短一點、算式一行一步；`×`、`√`、`θ`、`μ`、`ε`、`Φ`、`λ`、`→`、`′` 都有字。
`≈ − ≥ ≤ ✓ ⇒ ∝` 字型沒有，引擎會自動換成 `= - >= <= OK → ~`。

排版規則：一題盡量不跨頁；一題比一頁長時，會在 `(b)`、`(c)`… 開頭的 `t` 行前換頁。一頁約 25 行。

## 內建圖

單位是像素（建議 1 cm ≈ 20–30 px，讓圖寬不超過 `FIG_W` ≈ 1150 px）。幾何照比例，光線交點就是公式算出的像，所以**要用題目的真實比例**。

- `mirror_diagram(f, p, h, Vx_off=560)`：面鏡，鏡面朝左。`f>0` 凹面鏡、`f<0` 凸面鏡；`p` 物距、`h` 物高（建議 80–130，主軸上方只有約 170 px）；`Vx_off` 鏡子離圖左邊的距離，物體要能放得下（`Vx_off > p`）。
- `lens_diagram(f, p, h, Lx_off=520)`：薄透鏡。`f>0` 凸透鏡、`f<0` 凹透鏡；虛像會在透鏡左邊，`Lx_off` 要留空間。
- 兩者都畫兩條主光線，實像畫實線，虛像用虛線延長；`p == f` 時不畫像（不成像）。
- 先算放大率：像高 `|m|·h` 不要超過約 160 px（主軸上下各只有約 170 px），放大的像要把 `h` 調小。

自訂圖：寫一個 `def 圖(img, d, x0, y0)`（`x0, y0` 是圖框左上角，高度 = 行數 × `RULE`(76 px)），用 `wobbly_line`、`dashed_line`、`ray`（中段帶箭頭）、`vec_arrow`（尾端箭頭）、`arc`、`dot`、`label(img, 文字, x, y, col)` 畫，然後 `('fig', 圖, 行數)`。顏色有 `BLUE`、`RED`、`GRAY`。

## 換筆跡

`--seed N` 換數字，同樣內容會出不同的抖動。
